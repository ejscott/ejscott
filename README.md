## Current project

### [PalMac](https://github.com/ejscott/PalMac)

PalMac is an open-source mod manager and mod-authoring toolkit for the native Apple Silicon version of Palworld.

It supports Mac-compatible PAK and IoStore packages, includes a reproducible Unreal Engine 5.1.1 starter project, and documents the early workflow for creating and converting content mods for macOS.
